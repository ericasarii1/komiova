# KomiOva 🦸

Aplikasi web baca komik. Flask + vanilla JS.

## Fitur
- Daftar komik + cover
- Pencarian judul & genre
- Detail komik + daftar chapter
- Reader scroll vertikal, navigasi prev/next chapter
- Favorit (localStorage)

## Jalankan lokal
```
pip install -r requirements.txt
python app.py
```
